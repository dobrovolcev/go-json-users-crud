#Go JSON Users CRUD

Мини-проект на Go для работы с пользователями через JSON-файл.

Программа позволяет хранить список пользователей в `.json` файле и управлять им через консольное меню.

## Возможности

- загрузка пользователей из JSON-файла
- вывод всех пользователей
- добавление нового пользователя
- поиск пользователя по имени
- изменение возраста пользователя
- удаление пользователя
- сохранение изменений обратно в JSON-файл
- проверка возраста пользователя
- обработка ошибок при чтении, записи и работе с JSON

## Используемые темы Go

В проекте используются:

- структуры
- методы и функции
- срезы
- JSON tags
- `json.MarshalIndent`
- `json.Unmarshal`
- `os.ReadFile`
- `os.WriteFile`
- обработка ошибок через `error`
- собственный тип ошибки
- бесконечный цикл `for`
- `switch`
- работа с консольным вводом

## Пример JSON-файла

```json
[
  {
    "name": "Alex",
    "age": 20
  },
  {
    "name": "Bob",
    "age": 25
  }
]
```

## Как запустить

1. Склонировать репозиторий:

```bash
git clone https://github.com/dobrovolcev/go-json-users-crud.git
```

2. Перейти в папку проекта:

```bash
cd go-json-users-crud
```

3. Запустить программу:

```bash
go run main.go
```

4. Ввести имя JSON-файла, например:

```text
user.json
```

## Меню программы
